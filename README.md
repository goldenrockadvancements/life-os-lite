# Life OS — Lite (free)

A free Obsidian vault to organize your life: goals, projects, areas, habits, journaling and a weekly review, with a Home page that shows today. A calm second brain, no plugins, no subscription.

## Get started
1. Download this repo (**Code -> Download ZIP**) or clone it.
2. In Obsidian: **Open folder as vault** and pick this folder.
3. Start with `Home.md`.

## Free lite vs. the full $27 edition
This repo is the free **lite** edition. The full edition adds: the full goals / projects / areas / habits / journal / weekly-review system and dashboard views.
