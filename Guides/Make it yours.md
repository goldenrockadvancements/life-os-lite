- **Rename statuses or stages:** edit the template *and* the matching filter in the base (for example `status == "Active"`). Both use plain words.
- **Add a field:** add it to the template's properties, then tick it under *Properties* in the base.
- **Change the look:** *Settings > Appearance*. The small style file (*CSS snippets > golden-rock-vault*) can be switched off.
- **Different folders:** move anything. The bases find notes by their `type` property, so folders are just for you.
- **Daily notes:** click the calendar icon on the left (or `Ctrl/Cmd + P` > "Open today's daily note"). They use the *Daily note* template.
- **Keyboard shortcuts:** *Settings > Hotkeys*. A useful one to set: "Templates: Insert template".
