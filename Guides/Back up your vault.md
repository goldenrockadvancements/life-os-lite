Sync is not a backup: if you delete a note, sync deletes it everywhere. Keep **one real backup**:

1. **Simplest:** once a month, right-click the vault folder > *Compress* (Mac) or *Send to > Compressed folder* (Windows) and drop the ZIP in a cloud drive.
2. **Automatic:** include the vault folder in Time Machine (Mac) or File History (Windows).
3. **Obsidian's own safety net:** the *File recovery* core plugin (on in this vault) keeps snapshots of every note for 7 days. Find it in *Settings > Core plugins > File recovery > View*.

Put a reminder in your calendar on the 1st of each month: "Back up my vault". Test a restore once (open the ZIP, check a note), because a backup you've never restored is only a hope.
