A long list is hard to start. Three is doable.

1. Each morning (or the evening before), tick **focus** on up to 3 tasks. They show under *Focus today*.
2. Set the one you're starting to **Doing**. It shows under *Now*.
3. When it's done, set *status* to Done. Then the next one.

If you finish all three, that's a full day. Anything else is a bonus. If you finish one, that still counts.
