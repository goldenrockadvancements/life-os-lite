For each item in *Brain dump to sort*, pick one:

- **Do it now** if it takes 2 minutes or less. Then tick *sorted*.
- **Make it a task:** a note in `02 Tasks` with the **Task** template. Write the first physical step, set *energy* and *minutes*. Tick *sorted*.
- **Let it go.** Delete it. Not everything needs doing.

The full [Life OS](https://goldenrockadvancements.com/vaults/life-os/) adds goals, life admin with due dates, routines and a weekly reset.
